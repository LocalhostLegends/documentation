# Architecture Overview

## Tech Stack

- **Backend**: NestJS, TypeORM, PostgreSQL
- **Auth**: JWT, Bcrypt
- **Deployment**: Docker

## Modules

- Auth Module - Authentication
- Users Module - User management

## Security & Access Control

The platform implements a strict **[Role-Based Access Control (RBAC)](./rbac/roles-overview)** system to ensure data isolation and the principle of least privilege.
